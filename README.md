# 눈금동행

한 줄의 7세그먼트 숫자 표시를 읽고 단위를 직접 확인하며 소수점 자리를 연습하는 독립 교육 프로토타입입니다.

## 실행

`index.html`을 최신 브라우저에서 열면 오프라인으로 작동합니다. 설치, 계정, 외부 AI API가 필요하지 않습니다. 숫자 읽기 → 표시와 후보 직접 비교 → mm 또는 inch 선택 → 소수 둘째 자리 답안 입력 순서로 실행합니다. PNG/JPEG/WebP 파일을 고를 수 있으며 사진은 이 앱의 브라우저 메모리에서 처리합니다.

## 실제 구현 및 검증

직접 생성한 합성 7세그먼트 숫자 1,800개로 448입력×10클래스 선형 softmax 분류기를 160회 학습했습니다. 지정된 샘플 정답을 결과에 복사하지 않고 픽셀을 전처리해 모델을 실행합니다. 소수점은 이미지 구성요소로 찾으며 단위는 사람이 확인합니다.

같은 생성기의 별도 시드 합성 600개에서 600개 정답이었습니다. 더 큰 기울기·흐림 시험은 600개 중 585개 정답이었고, 모델 점수 0.9 이상 444개 중 4개가 오답이었습니다. 모델 점수는 보정된 정확도나 확률이 아닙니다. 실제 측정기 사진 정확도와 사용자 효과는 검증하지 않았습니다.

실제 브라우저에서 12.30/0.08/76.51/128.04/흐린 표시, mm·inch 변환, 소수점 오답·정답 피드백, PNG/JPEG/WebP 합성 숫자 8, 빈 이미지 거절, 잘못된 이미지 후 이전 값 해제, 다시 연습을 확인했습니다. 실제 좁은 화면 571 CSS px에서 가로 넘침이 없었습니다. 정확한 390px 검증은 수행하지 못했습니다.

## 한계 및 AI 사용

필기, 일반 인쇄체, 음수, 단위 글자가 포함된 사진을 지원하지 않습니다. 실제 길이 측정·측정기 교정·산업 품질 판정 용도가 아닙니다. 기획·코드 작성과 합성 학습/검증에는 Codex AI 에이전트를 사용했습니다. 실제 참가자 실사용 연구나 직접 현장 촬영을 주장하지 않습니다.

## 보안 및 비용

앱에 외부 요청, 사진 전송, 인증, 결제, 유료 API가 없습니다. 호스팅 서비스의 기본 접속 로그와 별개로 앱은 사용자 사진을 서버에 보내지 않습니다. 공개 저장소에는 개인정보·출품 신청서·서명·인증 자료를 포함하지 않습니다.

## 출품 범위

AI 라이프 솔루션 챌린지용 새 독립 프로토타입입니다. 이 저장소 공개만으로 대회 접수 완료를 의미하지 않습니다. 원본 자료 재배포 허락과 혼동되지 않도록 라이선스를 임의 부여하지 않았습니다.

비동기 이미지 처리는 선택 세대 번호를 확인합니다. 이전 파일의 늦은 처리 결과가 새 파일·샘플 변경·초기화를 덮지 않도록 수정했습니다. 별도 지연 완료 회귀 시험으로 확인합니다.
